# Varsity Tutors

> Varsity Tutors, a Nerdy company (NYSE: NRDY), is a live online learning platform
> connecting K-12, college, graduate and professional learners with expert instructors
> for private one-on-one tutoring, live classes, test preparation and diagnostics across
> more than 3,000 subjects. It also sells Varsity Tutors for Schools to districts.

IMPORTANT FOR AGENTS: Varsity Tutors publishes NO public API, NO developer portal, NO
machine-readable contract, NO SDK and NO MCP server. Do not attempt to integrate
programmatically. Everything below is either a human-facing web page or a first-party
host that is explicitly closed to third parties. This file is GENERATED by API
Evangelist from probed evidence; it is not published by Varsity Tutors.

## Company

- [Varsity Tutors](https://www.varsitytutors.com/): Learner-facing marketing and
  application site. Private tutoring, live classes, test prep, practice tests.
- [Nerdy Inc.](https://nerdy.com/): Parent company, NYSE: NRDY.
- [Blog](https://www.varsitytutors.com/blog): Company and learning-content blog.
- [Sign in](https://www.varsitytutors.com/login): Learner, tutor and district login.
- [Get started / pricing intake](https://www.varsitytutors.com/t/): Membership pricing
  is quoted after a needs questionnaire. No rate card is published.

## Integrations

- [Clever app gallery listing](https://www.clever.com/app-gallery/varsity-tutors/):
  The ONLY documented third-party integration surface. Varsity Tutors offers SSO through
  Clever Instant Login and rosters/provisions accounts through Clever Secure Sync. In
  both directions Varsity Tutors is a CONSUMER of Clever's API. Districts configure this
  from their Clever admin portal, not from a Varsity Tutors developer console.

## Hosts probed (all first-party)

- `www.varsitytutors.com` — marketing and learner web application.
- `api.varsitytutors.com` — first-party API gateway (`server: vt-apigw`, Phusion
  Passenger/Rails origin). Serves the Varsity Tutors web and mobile clients only. Its
  robots.txt reads `Allow: /vtwa/v1/link_blocks_directory/lookup` then `Disallow: /`.
  Undocumented, unversioned in public, no rate-limit headers, plain-text error bodies.
- `ai.varsitytutors.com` — AI-enhanced learning tools surface.
- `nerdyai.varsitytutors.com` — Nerdy AI product login surface.
